Architecture Overview

This proof-of-concept demonstrates an AI-assisted approach to data quality management using Python and a command-line interface. The solution is designed to allow non-technical users to explore and assess data quality by asking natural-language questions, which are safely translated into SQL queries and executed against an in-memory dataset. The architecture intentionally avoids unnecessary infrastructure to keep the PoC lightweight, transparent, and easy to evaluate.

At the core of the solution, data is loaded from Excel into a pandas DataFrame and normalized through a dedicated data cleaning layer. This layer handles mixed numeric locales, boolean normalization, date parsing, and basic schema harmonization. The cleaned dataset is then profiled to generate a compact schema description, including column types, missing value statistics, and candidate numeric and datetime fields. This schema is used both for human inspection and as structured context for the AI model.

User interaction happens via a CLI that supports three complementary modes: manual SQL queries, predefined data-quality checks, and natural-language questions powered by a large language model. All SQL execution is guarded by strict safety rules (SELECT-only, keyword filtering, automatic LIMIT enforcement) to prevent destructive or excessive queries. For explainability and domain understanding, the solution optionally augments the model with Retrieval-Augmented Generation (RAG), sourcing additional context from local documentation files. This modular design allows the PoC to be easily extended to a real SQL database, additional data sources, or a web-based interface in future phases.
